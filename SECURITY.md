# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Private Allowlist Access**, please report it responsibly.

- Do **not** open a public GitHub issue for security vulnerabilities.
- Send an email or private report to the maintainer (`Atanu2coder`).
- We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for resolution.
