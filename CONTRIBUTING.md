# Contributing Guidelines

Thank you for considering contributing to **Private Allowlist Access**!

## How to Contribute

1. **Fork the Repository**: Create your own feature branch from `main`.
2. **Setup Locally**: Follow the instructions in [README.md](README.md) to install dependencies and run the frontend.
3. **Commit Your Changes**: Use clear Conventional Commit messages (`feat:`, `fix:`, `docs:`, `test:`).
4. **Submit a Pull Request**: Provide a detailed description of your changes.

## Development Workflow

- Run `cd frontend && npm run build` before submitting a PR to ensure the build passes cleanly.
- Ensure all TypeScript types are checked without errors (`npx tsc --noEmit`).

Thank you for helping build the future of privacy on the Midnight Network!
